# KakaTools QR 產生器 計劃書（qr/）

> 2026-10-25 開。靈感來自 IG louis_rlee 介紹的 ICQR（連結長成 voxel 立體方塊樹、地面就是真 QR）。
> **我們做自己的版本，不抄它的程式、不用它的素材。**
> 這份文件是 qr 工具的唯一規格；實作派給 Codex，Claude 審查。

---

## 0. 一句話

貼一條連結 → 立刻出一個**一定掃得到**的 QR。可以做成風格化的 2D 圖，也可以變成一棵長在 QR 上的 3D 方塊樹，點一下樹就摺回平面讓人掃。

## 1. 硬規則（任何裝飾都不能違反）

1. **三個定位方塊（finder）＋外圍留白（quiet zone，至少 4 格）永遠不能被蓋到、不能被打散成圓點、不能被漸層弄淡。**
2. **每一張匯出的圖都必須掃得到。** 頁面內建自動驗證：每次畫面更新後，用 jsQR 把「要匯出的那張圖」解碼一次，解出來的內容必須等於輸入。
   - 通過 → 顯示「✅ 已驗證可掃描」，下載鈕可按。
   - 失敗 → 顯示「⚠️ 這個組合掃不到」＋原因提示（顏色太淡／logo 太大…），**下載鈕停用**。
3. 前景要比背景深（不做反白 QR，很多手機掃不到）；前景與背景的對比度 < 3:1 就警告並停用下載。
4. 純前端、零後端、零費用、不登入、不傳任何資料出去。所有函式庫**放在本地 vendor/**，不吃 CDN（GitHub Pages 斷 CDN 也照樣能用）。
5. 不加功能以外的東西：不做短網址、不做追蹤統計、不做帳號、不做 PWA、不改其他工具的檔案（首頁 index.html 只加一張卡）。

## 2. 函式庫（全部 vendor 進 `qr/vendor/`，附授權）

| 用途 | 函式庫 | 版本 | 授權 |
|---|---|---|---|
| 產生 QR 矩陣 | qrcode-generator（Kazuhiko Arase） | 2.0.4 | MIT |
| 3D | three.js（`three.module.min.js` + `OrbitControls.js`） | 0.170.0 | MIT |
| 掃描自我驗證 | jsQR（cozmo） | 1.4.0 | Apache-2.0 |

- `qr/vendor/LICENSES.md` 列出三個函式庫的名稱、版本、來源網址、授權全文或連結。
- **只拿 qrcode-generator 的「黑白矩陣」**，2D 和 3D 都自己畫，同一份矩陣兩邊共用 → 2D 和 3D 平面態永遠是同一個 QR。
- 為什麼不用 qr-code-styling：它只出 2D 圖，3D 還是要矩陣；自己畫比較好控制「定位方塊不准動」這條硬規則。
- 環境音用 Web Audio 即時合成（風聲白噪＋偶爾鳥叫），**不放音檔**，避免素材授權問題。

## 3. 檔案結構

```
KakaTools/qr/
├── index.html          ← 頁面骨架（zh-Hant），importmap 指到 vendor/three
├── style.css           ← 沿用 KakaTools 暖紙色系（--paper #fffaf2、--coral、--teal…）
├── app.js              ← 輸入、設定面板、狀態、下載、驗證（ES module）
├── qr-core.js          ← 字串 → 矩陣（包 qrcode-generator）、finder/留白區判斷
├── render2d.js         ← 矩陣 → canvas（PNG）與 SVG 字串，兩者同一套參數
├── scene3d.js          ← three.js 場景：地面 QR、樹生成、季節、摺回動畫、匯出
├── ambient.js          ← Web Audio 環境音
├── verify.js           ← jsQR 驗證（吃 canvas，回傳 ok/內容/原因）
├── vendor/             ← qrcode-generator.js、three.module.min.js、OrbitControls.js、jsQR.js、LICENSES.md
└── tests/scan-matrix.html ← 驗收用：把所有風格組合各畫一次、各驗一次，列出通過/失敗表
```

不用 build、不用 npm、不用 node_modules；跟其他工具一樣直接被 GitHub Pages 讀。

## 4. 畫面

### 4.1 共用版面
- 頂部 nav：`← KakaTools`（回首頁）＋右邊「QR 產生器 🌳」。
- 輸入框：貼連結或任何文字，**即時**更新（輸入停 200ms 後重畫）。超過 300 字元顯示「內容很長，QR 會很密，建議用短一點的連結」但仍可產生。
- 模式切換（大分頁鈕）：**2D 風格** ／ **3D 小樹**。
- 預覽區＋下方驗證徽章（✅/⚠️）＋下載鈕。
- 桌機：左預覽、右設定；手機（≤760px）：上預覽、下設定，設定分段可收合。整頁不能橫向捲動。
- 設定存 localStorage（try/catch 包住，讀不到就用預設），只存外觀設定，**不存輸入的連結**。

### 4.2 2D 風格模式
設定項：
- **前景色／背景色**（color input）＋ 4 組預設配色（KakaTools 珊瑚、薄荷、墨藍、經典黑白）。
- **漸層**：無／線性（可選角度 0/45/90/135）／放射；兩個色票。漸層兩端都要過對比度檢查。
- **資料點形狀**：方塊／圓角方塊／圓點／相連圓角（相鄰同色格連成膠囊）。圓點直徑不可小於格寬 80%。
- **定位方塊形狀**：方／圓角（2026-10-25 審查時拿掉「圓」：jsQR 掃得到，但 OpenCV 解不到，舊型掃描器風險高）。**一定是實心外框＋實心中心**，不受資料點形狀影響、不吃漸層透明度（可吃漸層顏色，但兩端都要夠深）。
- **容錯等級**：L / M / Q / H，預設 M；**上傳 logo 時自動切到 H 並鎖住**（UI 提示原因）。
- **中間 logo**：上傳圖片（只在本機讀，不上傳）；大小滑桿 10%–22% 邊長，預設 18%；logo 後面墊一塊圓角背景色底板，底板蓋掉的格子算進 logo 面積。logo 區不得碰到三個定位方塊與 timing 線；中央的 alignment pattern 可以被蓋（H 容錯補得回來，且一律過驗證），否則長網址時 logo 會直接消失。
- **留白**：4–8 格，預設 4，**最小 4 不能再小**。
- **輸出尺寸**：512 / 1024 / 2048 px，預設 1024。
- 下載：**PNG**、**SVG**。SVG 驗證方式＝先把 SVG 畫到 canvas 再丟 jsQR。

### 4.3 3D 小樹模式（我們自己的 ICQR 版本）
概念：QR 是一塊方塊地面，深色格是深色方塊、淺色格是淺色方塊（像草地／泥土），上面長一棵 voxel 樹。

- **地面**：每一格一個扁方塊（InstancedMesh）。深色格＝深色系（季節決定，例如春天深綠、秋天深棕），淺色格＝淺色系（米白/淺草色），**每格可有一點亮度隨機變化增加質感，但深色格和淺色格的明暗差距必須夠大**（深色格 L* ≤ 35、淺色格 L* ≥ 75，用 HSL/Lab 範圍鎖死，不准讓 random 越界）。留白一圈也是淺色方塊地面。
- **樹**：用輸入字串算 hash 當亂數種子 → **同一條連結永遠長出同一棵樹**。樹幹（棕色方塊，3–6 格高，可能分 1–2 個枝）＋樹冠（不規則球形 voxel 團，帶些空洞與垂葉）。樹種在 QR 中心，樹幹底部佔的格子不能壓在三個定位方塊上。
- **季節**（三個按鈕）：
  - 春：嫩綠樹冠＋點點粉紅花方塊，偶爾有花瓣方塊飄落。
  - 夏：濃綠飽滿樹冠，地面淺色格偏草綠（仍要符合 L* 範圍）。
  - 秋：橘/紅/黃混色樹冠，葉片方塊慢慢飄落、在地上堆幾片（**落葉只在 3D 樹景出現，摺回平面時要清掉**）。
- **葉子顏色**：6 個色點（綠、粉、紅、橘、藍、紫），覆蓋季節預設的樹冠主色。
- **操作**：OrbitControls 可拖曳旋轉、雙指縮放（限制角度不能鑽到地底）；一開始緩慢自轉，使用者一碰就停。
- **摺回平面**：點樹（raycast 打到樹）或按「摺回 QR」鈕 → 樹的方塊依序縮小/落下收進地面（約 1.2 秒）→ 鏡頭轉成正上方俯視、地面方塊壓平 → 變成可掃描的平面 QR。再按「長出小樹」反向播放。
- **環境音**：右下喇叭鈕，**預設關**；開了才建立 AudioContext（符合瀏覽器自動播放政策）。風聲＋季節小變化（春夏鳥叫、秋天風大一點）。
- **匯出**（兩顆鈕）：
  1. **「下載可掃描 QR」**：用正上方平面態算出的 PNG（直接用同一份矩陣＋地面配色畫 2D，不是截 WebGL 畫面），一定先過 jsQR 驗證。
  2. **「下載樹景海報」**：當前 3D 視角的截圖（直立長方形，例如 1080×1350），**右下角或底部自動附一張已驗證的平面 QR 卡**，所以海報本身也掃得到。海報整張也要過 jsQR。
- 效能：pixelRatio 上限 2；樹＋地面全部用 InstancedMesh；手機上維持流暢（目標 iPhone 上 ≥ 30fps）。WebGL 不支援時，3D 分頁顯示「這台裝置不支援 3D，請用 2D 模式」，不要整頁壞掉。
- 不做：冬天、雪、多棵樹、自訂樹形、動畫錄影匯出（之後再說）。
